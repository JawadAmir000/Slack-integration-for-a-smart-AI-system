📚 Code Example

Here's how this example uses the SlackRealTimeClient library:

// Initialize the client const client = new SlackRealTimeClient({ host: window.location.host, secure: window.location.protocol === 'https:', debug: true, enableReconnection: true, maxReconnectAttempts: 5 }); // Listen for different types of messages client.on('channel_message', (message) => { addMessage(`📢 Channel: ${message.text}`, 'channel'); }); client.on('direct_message', (message) => { addMessage(`💬 DM: ${message.text}`, 'dm'); }); client.on('connected', () => { updateStatus('connected', 'Connected via Client Library'); }); // Connect to Slack client.connect();

🎯 Available Events

  • connected - Successfully connected to Slack
  • disconnected - Disconnected from Slack
  • channel_message - New channel message received
  • direct_message - New direct message received
  • typing - User typing indicator
  • reaction - Message reaction added/removed
  • notification - General notifications
  • error - Connection or parsing errors
  • reconnecting - Attempting to reconnect

⚡ Features

  • Automatic Reconnection: Reconnects automatically with exponential backoff
  • Message Queuing: Queues messages when disconnected and sends when reconnected
  • Performance Monitoring: Tracks latency, uptime, and error rates
  • Event-Driven: Clean event-based API for handling different message types
  • Heartbeat: Keeps connection alive with periodic ping/pong
  • Subscriptions: Subscribe to specific workspaces or channels
