Available API Endpoints
Authentication
  • GET /api/slack/auth/initiate/ - Start OAuth
  • POST /api/slack/auth/callback/ - Handle OAuth
Messages
  • POST /api/slack/messages/send/ - Send message
  • POST /api/slack/messages/reaction/ - Add reaction
Channels
  • GET /api/slack/channels/ - List channels
  • POST /api/slack/channels/ - Create channel
  • POST /api/slack/channels/join/ - Join channel
Files & User
  • POST /api/slack/files/upload/ - Upload file
  • GET /api/slack/user/info/ - Get user info
